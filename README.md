FixFlow – Tài khoản cá nhân

1. Giới thiệu

Đây là trang 13 – Tài khoản cá nhân thuộc dự án FixFlow, được xây dựng bằng HTML, CSS và JavaScript.

2. Công nghệ sử dụng

HTML5: Xây dựng cấu trúc trang web.

CSS3: Thiết kế giao diện.

JavaScript: Xử lý các tương tác.

3. Chức năng chính

Hiển thị thông tin cá nhân.

Chỉnh sửa thông tin trên giao diện.

Kiểm tra dữ liệu đổi mật khẩu.

Cài đặt thông báo.

Hiển thị hộp thoại xác nhận đăng xuất.

Lưu ý: Đây là giao diện frontend demo, chưa kết nối máy chủ hoặc hệ thống xác thực tài khoản thật.

4. Cấu trúc dự án

index.html: Cấu trúc trang web.

css/style.css: Định dạng giao diện.

js/main.js: Xử lý tương tác.
